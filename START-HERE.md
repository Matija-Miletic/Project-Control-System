# Start here

1. Keep this entire folder together.
2. Double-click `index.html`.
3. Allow JavaScript for the local file if the browser asks.
4. Confirm the top-right status says the project is saved locally.
5. Use **Export project** to create a complete JSON backup after meaningful work.

There is no installer, account, server, package manager, build command or
internet requirement.

Recommended browser: current Firefox, Chrome or Edge. Do not use a private
browsing window for operational data because private storage may be discarded
when the window closes.

Open `help.html` for the full operating guide.
