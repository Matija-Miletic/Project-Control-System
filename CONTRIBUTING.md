# Feedback and contributions

The fastest way to help is to open a
[GitHub issue](https://github.com/Matija-Miletic/Project-Control-System/issues/new)
with:

- the page and feature involved;
- what you tried to do;
- what happened and what you expected;
- a screenshot when layout or interaction is involved;
- browser and screen size when relevant.

Do not include real project records, client documents, personal information,
credentials or other confidential material.

For code changes, keep calculation changes and their tests in the same pull
request. Run `npm test`, `npm run lint` and `npx tsc --noEmit` before submitting.
